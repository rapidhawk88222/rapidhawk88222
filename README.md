# Hey there

I'm a developer who spends most of my time writing Python scripts that make repetitive tasks disappear. Automation is the part of coding I enjoy the most — taking something that used to take twenty minutes and turning it into a one-liner that runs while I grab coffee.

Lately I've been digging into open source more seriously. Not just using libraries, but reading the code, filing issues when things break, and occasionally sending small pull requests. There's something satisfying about fixing a bug that other people will actually run into. I try to keep my contributions practical: better error messages, clearer docs, or a missing test that catches an edge case.

I also like building small developer tools for myself. Command-line helpers, config generators, little utilities that sit between me and the friction of everyday work. Most of them never leave my machine, but the ones that do tend to be the ones other people find useful too.

### What I care about

- Writing clean, readable Python that other humans can maintain
- Automating the boring parts of development and ops
- Contributing to projects I actually use
- Tools that reduce context-switching and cognitive load

I'm not chasing the next big framework or hype cycle. I prefer solid foundations, good documentation, and code that does one thing well. If that sounds familiar, feel free to look around or open an issue on something you're working on. Always happy to talk about automation patterns, Python packaging quirks, or how to keep a side project from becoming a second job.

Outside of code I reset by walking, tinkering with Linux setups, and occasionally rewriting the same script for the third time because the second version still felt wrong.

Thanks for stopping by.
